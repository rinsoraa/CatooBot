## 1. G3 剩余真实负向矩阵

在正常 `Bot.start` 装配、隔离临时 SQLite、公开测试 Bible、真实测试服上，补齐并逐项保存：

1. **工具/耐久**：错误工具、接近耗尽耐久、工具在确认前变化；必须零破坏或明确非成功，不得先破坏再猜失败。
2. **必要事实缺失/过期**：观察缺失、覆盖不足、计划冻结后事实过期、维度/在线状态变化；派发前复核必须拒绝或重规划，不得使用旧事实。
3. **路径失败**：不可达、不可站立、目标被阻挡；失败后不得额外破坏/放置/传送绕路，不得伪造移动成功。
4. **旧掉落 / 合并 / 其他玩家**：预置同类旧掉落、合并掉落、其他玩家破坏或拾取；不得把旧实体、旧事件或他人行为计入本任务成功或库存净增。
5. **库存不净增**：背包满、同类物品未实际增加、拾取被他人抢先；必须保持 UNKNOWN 或既有非成功状态。
6. **资源特有危险**：支撑缺失、边缘/坠落、相邻液体、上方重力块；按资源合同逐项拒绝，已有 gravity 结果保留。
7. **逐 ID STOP/CANCEL**：每个支持 ID 至少一次真实执行窗口内的停止/取消，保存两次延后坐标、唯一终态与不再派发证据；已有 84 项 cancel_move 结果不得被本轮覆盖或删除。

矩阵按 12 个支持 ID 建表；每个 ID 明确列出适用类别、执行/拒绝结果、世界前后状态、服务端/独立观察和库存前后。夹具命令与产品动作分开记录。原 84 项负向矩阵继续作为已通过证据保留。

## 2. G4 真实 QQ 文案复测

仅使用用户授权的杏仁罐头私聊与罐头商铺群聊；其他会话不触达。

- 复测歧义请求（如“采集一块木头，白桦还是云杉我没决定。”）与否定/询问请求；
- 回复不得包含内部原因码（如 `resource.intent.*`），不得声称“看了一圈”或暗示已观察世界；
- 记录真实投递的 conversation turn、回复文本、任务表零新增、工具日志零动作；
- 不把受控 transport 或隔离 profile 结果冒充真实 QQ；不宣称 QQ 正向采集通过。
