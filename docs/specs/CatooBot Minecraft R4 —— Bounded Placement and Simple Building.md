# CatooBot Minecraft R4 —— Bounded Placement and Simple Building

开工归档：2026-10-21。验收完成：2026-10-22，R4-A1–A6 全部 PASS；发布 `7c3a5a4`，CI 39638936965 三 job success。前置 R3 COMPLETE。

## 1. 目标与首期支持集

允许少量、明确目标、固定区域的方块放置；不支持无限自由建造、自动搭桥/拆除、大面积地形改造、爆炸物或红石机关。

首期支持：

- 单一材料（同一物品 ID）；
- 1–4 个目标格，全部位于以玩家为中心的 3×3×3 固定区域内；
- 每个目标格明确坐标、face（up/down/north/south/east/west）、参考方块与当前主手物品；
- 目标格必须为空气，参考方块必须为可依附实体方块，不能覆盖未知/液体/已有方块；
- 只使用当前主手物品，不自动装备、不自动合成、不自动补货、不自动导航；
- 工作台、火把、泥土/圆石等简单方块优先作为真实矩阵对象；
- 不把 R4 能力用于资源采集绕行；采集仍走 R3 合同。

## 2. 合同与门禁

### R4-A1 请求与区域合同

- 解析/接收明确的 build 请求：材料、数量、目标格列表、face、区域边界、维度；
- 校验材料在支持物品集合内、数量 1–4、目标格不重复、全部在固定区域、坐标整数且在 Minecraft 世界边界内；
- 未知材料、超量、越界、重复格、目标已占用、参考方块空气、主手物品不符或数量不足时，在规划前拒绝，不产生世界动作。

### R4-A2 授权与冻结

- 计划冻结目标格、材料、数量、face、区域边界、维度、plan_hash；
- 确认前零世界修改；MEDIUM 风险必须用户确认；
- 授权绑定 plan_hash/plan_version，过期、旧版本、错误 owner、错误 session 不得执行；
- 不因记忆、LIFE、技能或旧计划扩大材料、区域或数量。

### R4-A3 逐格执行与验证

- 每个目标格一个 `minecraft_place` 步骤，记录 action_id；
- 放置前 runtime 重新读取目标/参考/主手/距离；外部占位变化、方块被替换、参考方块消失时拒绝执行；
- 放置后必须真实读取目标方块并匹配 expected_item，不能以 Promise/推断宣告成功；
- 只有全部目标格逐格成功且最终读回一致才可 SUCCEEDED；部分完成、未知、失败必须保持非成功状态。

### R4-A4 取消、超时、部分完成与恢复

- 确认后、下一格派发前响应 STOP/CANCEL；已放置的格子如实保留，不得自动拆除或回滚成假成功；
- 超时、断线、重启、外部变化均记录唯一终态和已完成格数；
- 部分完成明确标记 PARTIAL/FAILED/UNKNOWN 语义，不宣告完整建造成功。

### R4-A5 真实服务器矩阵

在测试服上用正常 `Bot.start` 装配、隔离 SQLite、公开测试 Bible 执行：

1. 单块工作台/火把等合法放置：确认前零修改，确认后逐格读回一致；
2. 2–4 格简单直线/小结构：全部逐格成功；
3. 材料不足、错误主手、目标占用、参考方块缺失、越界、重复格：规划前拒绝，零世界动作；
4. 外部占位变化/参考方块消失/执行中 STOP：非成功或部分完成，已放置格保留且不复活；
5. 错误 owner、过期授权、旧 plan_hash、重启恢复：不得执行；
6. 测试结束恢复本轮新快照并逐文件哈希核对。
