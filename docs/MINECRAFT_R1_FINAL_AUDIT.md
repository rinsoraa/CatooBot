## 裁定

R1 的功能出口在所测 **Fabric 1.21.1 dedicated server** 范围取得合格证据；本轮新增 16 个真实产品导航用例全部通过，补齐重复高差任务与固定绕障合同中的证据不足，P3 已关闭严格模式范围的 N9-B。产品代码未改，676 个产品/测试实现文件与上述已通过 CI 的版本哈希一致。

本轮文档与证据发布仍须提交前备份、凭据扫描和对应 CI 全部成功；完成前不开始 R2。Integrated/LAN 没有本轮验收，不据此宣称模组全面兼容；它仍是完整 R8 目标前的独立必需工作。R2–R8 均未因本审计提前完成。

## 首次失败、工程复用与恢复

首轮在新区域生成时超过夹具 RCON 的 3 秒读取等待，产品任务数为零，Java 正常保存并 exit 0。只将夹具等待改为 30 秒并放入线程，避免阻塞产品事件接收；生产导航预算、距离和 pathfinder 参数未改。第二轮 16 项全部通过，Java 正常 stop、全维度保存、自然 exit 0（1765ms），HTTP/outbox 退出通过。

复用精确相同代码版本的 P3 工程结果：Python 4705 通过、完整 npm test、完整 Java 160 断言及 Smoke、ruff/format、mypy 和远端三 job 首次成功。P3 的真实 Provider 五类语义与 QQ 零 Agent/工具反例亦作为未变入口的当前证据，不伪称本阶段重新发送过这些消息。纯文档/证据补充不重复相同全量测试；本轮提交仍校验文档、diff、凭据与 CI。

本轮重新对当前运行现场保存停服备份 99 文件，SHA-256 `2859daea7340281ddabdf81178b6367d24e163830f20d000b0984e24ee2791e1`；没有恢复到 P3 开工前的更旧世界。结束后逐文件恢复哈希一致、无额外世界文件、移除本轮模组和私有 token/RCON 配置，原服务器以 42 模组重新启动至 Done。日常 CatooBot 配置与角色未改。
