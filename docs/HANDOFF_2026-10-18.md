## 2. 实际架构

Python 3.12 进程以 `run.py` / `app/core/bot.py` 装配各域；OneBot/NapCat 提供 QQ 接入，aiohttp 提供 WebUI 后端，Vue 3/TypeScript 提供前端。Minecraft 通过独立 Node/Mineflayer HTTP runtime 连接。SQLite 承载角色、活动、任务、身份、记忆与技能记录。

| 层 | 实际源码 | 责任与边界 |
|---|---|---|
| 角色与 Life | `app/character/`、`app/sandbox/`、`app/activity/`、`app/initiative/` | 人格/生活/活动/Episode/Goal，LifeIntent 只是意图候选 |
| 社交与记忆 | `app/social/`、`app/conversation/`、`app/continuity/`、`app/memory/` | QQ 社交、会话连续性、检索；记忆不提供执行授权 |
| 提案与计划 | `app/tasks/proposal_service.py`、`agent_service.py`、`agent_planner.py` | TaskProposal、AgentPlan、冻结计划、风险/能力/目标检查 |
| 任务执行 | `app/tasks/runtime.py`、`app/integrations/minecraft/task_adapter.py`、`task_coordinator.py` | 确认、授权、动作派发、终态事件对账、恢复与停止 |
| MC 工具桥 | `app/integrations/minecraft/agent.py`、`service.py`、`chat_bridge.py` | MinecraftAgentBridge、Policy 与 Service；不同入口并非逐字经过架构图中每个组件 |
| 客户端动作 | `minecraft_runtime/runtime.js`、`action_runtime.js`、`dig_attribution.js` | Mineflayer 观察、动作预算、取消与结果，当前时序推断不等于严格自证 |
| 服务端证据 | `server_mod/`、`app/integrations/minecraft/attribution_shadow.py` | Fabric 玩家事件、会话/预约/HMAC/维度/UUID、独立影子接收与统计；未进入任务终态 |
| Learning | `app/tasks/skill_learning.py`、`skill_service.py`、`skill_store.py`、`skill_planner.py` | 证据资格、技能候选与适用性判断；严格挖掘证据不足会拒绝正向学习 |

核心结论：Life、Play、Learning 的基础设施已经存在，不能重新搭建第二套执行器。伴侣模组当前是证据层，不能视作 AI 或新增授权来源。

## 4. 任务书 28：本轮完成的修改

任务范围见 [任务书 28](specs/CatooBot%20Taskbook%2028%20%E2%80%94%20Handoff%20Baseline%20and%20Mod%20Delivery%20Gates.md)。

1. `sync_github.py` 增加模组源码及明确文件清单，排除生成包和服务器实际配置；遍历时直接剪除依赖/缓存目录。
2. `--check` 只报告差异，存在差异退出 1，无写入；缺失必需源码先整体报错，不再静默跳过后继续删除镜像文件。
3. push 前生成独立发布快照、清单和哈希，备份失败不进入 staging；不接管已有 staged 改动，使用限定路径 staging。
4. 构建读取固定 Minecraft/Fabric 依赖，JDK 21 从 JAVA_HOME/PATH/参数获得；每个编译/打包命令校验退出码；隔离 staging，编译失败保留旧包；归档时间戳固定。
5. 新增 `server_mod/test.ps1`：默认运行 Booking/Dimension 35 项；指定测试服只读依赖时完整编译并运行 EventJson/ReserveBridge/Smoke，共 46 项断言及类加载。
6. CI 增加 Windows + JDK 21 纯逻辑契约 job。CI 此 job 不执行 Fabric 全编译或 E3，覆盖范围明确标注。
7. 增加 8 项同步/隐私排除/只检查/备份/失败阻断/staging 顺序回归；修订过时的模组 README，并归档本次产品定义和路线图。

产品任务源码、授权、确认、终态与运行配置均未改动；本轮未启动 QQ 会话、部署模组、操作测试世界或重做 P2 E3。
