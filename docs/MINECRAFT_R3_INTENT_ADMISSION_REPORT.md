## 本轮实现

- `resource_intent` 是执行准入的共享合同：12 ID、最长别名、明确种类、通用木材候选、否定/询问/未知/歧义及数量预算。云杉/白桦不会再在通用入口变成橡木；沙子/泥土与其他支持资源使用相同入口。超预算不能改成较小可执行请求；多次采集指令不能悄悄只取第一件。
- USER 任务创建、重规划、未指定 shape 的 LIFE 规划、直接模板及技能包装消费同一合同。Minecraft 木材路由保留既有语义解释器与词法辅助，但在进入计划层之前用相同准入合同否决未知种类、数量或序列；旧词法结果本身没有执行权。
- 原文参与校验和冻结：创建/确认校验同时检查候选及原始目标；模型不能改写否定或种类后取得执行计划。较长请求不先截掉尾部再解析。观察返回的方块种类必须符合请求；木材候选不能混入另一个树种。
- 技能保留检索、绑定及学习反馈，物化时通过共享模板重新取得 SAFE 世界/工具事实，不能复活旧坐标和附近掉落首项引用。目标、工具或产物条件冲突时回退到正常规划，风险权限不变。本轮不宣称已完成 R7 的真实长期技能复用验收。
- 任务校验增加采集证据图：collection 标记、明确手持状态、本次 dig 的掉落实体 ID/UUID/parent action、对应物品、逐 dig 唯一拾取、数量/同列相邻约束及最终库存读取。缺少采集步骤的采集承诺也被拒绝。持久化旧计划在新确认前重新检查，失败时作废确认，不能靠旧历史绕过。
- 在上限内请求两根、观察只证明一根时，公共确认摘要明确列出原请求和本次执行数量；不把超预算请求截断后确认。明确移除一个指定方块的原子请求继续经过原 P3 确认与权限链。
- Provider 提示从资源注册表列出白名单，补充工具事实由系统读取、明确歧义/超量必须澄清的说明。提示不授予权限，确定性合同继续独立执行。
